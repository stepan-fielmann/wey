Performance overview

LatencyErrorsCosts

Latency

Median request latency fell for the third quarter in a row. Most of the gain came from moving session lookups to the edge cache, which removed a round trip for about two thirds of requests.

The long tail remains in report exports, which still run on the old worker pool. They move with the billing migration next month.

Errors

Error budgets held in every region. The one breach, a forty-minute partial outage in the payments callback, came from an expired certificate. Rotation is now automated.

Client-side errors dropped after the design system update removed two legacy date pickers.

Costs

Compute went down 8% while storage grew 12%, mostly from keeping full-resolution uploads. A lifecycle policy for originals older than a year would recover most of that.

Network costs are flat. The CDN contract renews in January.

Next quarter

Retire the old worker pool, finish the billing migration and publish the accessibility review of the booking flow.
